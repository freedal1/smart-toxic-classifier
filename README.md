# 🚀 Smart Toxic Classifier

## 📌 Описание проекта

Smart Toxic Classifier — система автоматической классификации комментариев на токсичные и нетоксичные.

Цель проекта — разработать модель машинного обучения, которая способна определять токсичность текста и возвращать вероятность принадлежности комментария к токсичному классу.

Модель получает текст сообщения и выполняет бинарную классификацию:

- `0` — Non-toxic
- `1` — Toxic

Проект выполнен как NLP-задача с использованием современных методов обработки естественного языка и трансформерной модели RuBERT.

# 🤖 Модели

В проекте сравниваются два подхода.


## 1. TF-IDF + Logistic Regression

Базовая модель машинного обучения.

Использует статистическое представление текста через TF-IDF признаки.

Преимущества:

- быстрое обучение;
- простая интерпретация;
- небольшой расход ресурсов.


Недостатки:

- не учитывает контекст;
- анализирует слова независимо друг от друга.


---

## 2. RuBERT

Основная модель проекта.

Используется предобученная трансформерная модель:

```
cointegrated/rubert-tiny2
```

Модель была дообучена на датасете токсичных комментариев.


Преимущества RuBERT:

- учитывает контекст слов;
- анализирует смысл предложения;
- лучше работает со сложными языковыми конструкциями.


После обучения модель сохранена в директории:

```
models/

├── config.json
├── model.safetensors
├── tokenizer_config.json
└── tokenizer.json
```

# ⚙️ Обучение модели

Перед обучением были выполнены следующие этапы:

1. Загрузка и анализ датасета.
2. Разделение данных на обучающую и тестовую выборки.
3. Токенизация текста с помощью RuBERT tokenizer.
4. Подготовка Dataset для Hugging Face.
5. Fine-tuning модели RuBERT.
6. Оценка качества модели.


Разделение данных:

```
Train: 11529 объектов

Test: 2883 объекта
```


Для оценки качества использовались метрики:

- Accuracy
- Precision
- Recall
- F1-score


Основной метрикой проекта является F1-score, так как она учитывает баланс между Precision и Recall.


---

# 📈 Результаты моделей

Обе модели тестировались на одинаковой тестовой выборке.


| Model | Accuracy | Precision | Recall | F1-score |
|------|----------|-----------|--------|----------|
| TF-IDF + Logistic Regression | 0.876 | 0.807 | 0.813 | 0.810 |
| RuBERT | 0.915 | 0.865 | 0.885 | 0.875 |


---

# 📌 Вывод

Использование трансформерной модели RuBERT позволило значительно улучшить качество классификации.


По сравнению с TF-IDF + Logistic Regression:

- Accuracy увеличилась с **0.876 до 0.915**
- Precision увеличился с **0.807 до 0.865**
- Recall увеличился с **0.813 до 0.885**
- F1-score увеличился с **0.810 до 0.875**


RuBERT показывает лучший результат благодаря способности учитывать контекст предложения, а не только наличие отдельных слов.
