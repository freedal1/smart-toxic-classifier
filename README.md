# 🚀 Smart Toxic Classifier

## 📌 Описание проекта

Проект представляет собой систему автоматической модерации комментариев.

Цель — определить, является ли комментарий токсичным или нет.

Модель получает текст сообщения и возвращает:

- класс комментария:
    - `0` — не токсичный
    - `1` — токсичный
- вероятность уверенности модели

Проект выполнен как NLP-задача бинарной классификации текста.

# 🤖 Модели

В проекте сравниваются два подхода:

## 1. TF-IDF + Logistic Regression

Базовое решение.

Плюсы:
- быстрое обучение;
- простая интерпретация.

Минусы:
- не учитывает контекст предложения.


## 2. RuBERT

Используется предобученная трансформерная модель для русского языка.

Преимущества:
- понимает контекст;
- учитывает взаимосвязь слов;
- лучше работает со сложными фразами.


---

# 📈 Результаты моделей


| Model | Accuracy | Precision | Recall | F1-score |
|-|-:|-:|-:|-:|
| TF-IDF + Logistic Regression | 0.876 | 0.807 | 0.813 | 0.810 |
| RuBERT | 0.915 | 0.865 | 0.885 | 0.875 |


## Вывод

Использование RuBERT позволило улучшить качество классификации:

- F1-score увеличился с **0.810 до 0.875**
- Recall увеличился с **0.813 до 0.885**

Transformer-модель лучше понимает смысл комментариев благодаря анализу контекста.

# ⚙️ Установка


Клонирование репозитория:

```bash
git clone https://github.com/freedal1/smart-toxic-classifier.git
```


Создание окружения:

```bash
python -m venv .venv
```

Активация:

MacOS/Linux:

```bash
source .venv/bin/activate
```


Установка зависимостей:

```bash
pip install -r requirements.txt
```
